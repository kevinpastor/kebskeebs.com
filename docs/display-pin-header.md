# 11. Display Pin Header

1. Insert the pin header into the back side of the display.
2. Tape down the pin header.
3. Flip over the display.
4. Solder the edge pins.
5. Verify the alignment of the pin header relative to the display.
6. Solder the remaining pins.
7. Remove the tape.
