# 4. Power Switch

![Power switch overview](/docs/power-switch/power-switch-overview.png)
![Power switch underside](/docs/power-switch/power-switch-underside.png)

The slide switch (Alps Alpine SSSS811101) goes on the **top side** of the PCB.

The switch has small plastic bumps (bosses) on the underside that align with holes in the PCB. If you chose a variant without bosses, align it manually so the legs sit flat in the footprint.

1. Place the switch in its footprint. The legs are asymmetric so it only fits one way; the bosses (if present) should drop into the alignment holes.
   ![Power switch positioned](/docs/power-switch/power-switch-positioned.png)
2. Solder all the legs.
   ![Power switch soldered](/docs/power-switch/power-switch-soldered.png)

> **Verify:** Slide the switch back and forth. It should move smoothly between both positions.
