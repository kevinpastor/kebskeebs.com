# 4. Power Switch

![Overview](/docs/power-switch/overview.png)

Depending on the model, the button might have small plastic bumps (bosses) on its underside to help with alignment.

> TODO Mention that the battery only charges when the switch is on.

![Power switch underside](/docs/power-switch/power-switch-underside.png)

1. Position the switch on the top side of the PCB.
    - Ensure the slider is on the outer edge of the PCB. The legs are asymmetric, so it only fits one way. The switch bosses, if present, should drop into the alignment holes.

    ![Power switch positioned](/docs/power-switch/step-1.png)

2. Solder all seven legs.

    ![Power switch soldered](/docs/power-switch/step-2.png)
