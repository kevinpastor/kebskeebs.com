# 4. Power Switch

![Overview](/docs/power-switch/power-switch-overview.png)

The power switch goes on the **top side** of the PCB.

Depending on the model, the button might have small plastic bumps (bosses) its underside, to help with alignment.

![Power switch underside](/docs/power-switch/power-switch-underside.png)

1. Position the switch. Ensure the slider is on the outer edge of the PCB. The legs are asymmetric, so it only fits one way. The switch bosses, if present, should drop into the alignment holes.
   ![Power switch positioned](/docs/power-switch/power-switch-positioned.png)
2. Solder all seven legs.
   ![Power switch soldered](/docs/power-switch/power-switch-soldered.png)
