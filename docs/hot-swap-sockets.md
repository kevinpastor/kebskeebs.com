# 2. Hot-Swap Sockets


[![Overview](/docs/hot-swap-sockets/overview_thumbnail.png)](/docs/hot-swap-sockets/overview.png)

The following steps apply to **all 35 sockets**. Complete all steps for each socket one at a time, or perform each step across all sockets before moving to the next.

1. Pre-tin the bottom-right pad for a socket on the back side of the PCB.

    [![Hot-swap socket soldered right pad](/docs/hot-swap-sockets/step-1_thumbnail.png)](/docs/hot-swap-sockets/step-1.png)

2. Position the socket.

    [![Hot-swap socket positioning](/docs/hot-swap-sockets/step-2_thumbnail.png)](/docs/hot-swap-sockets/step-2.png)

3. Reheat the pre-tinned pad while pushing the socket into position.

    [![Hot-swap socket soldered right side](/docs/hot-swap-sockets/step-3_thumbnail.png)](/docs/hot-swap-sockets/step-3.png)

4. Solder the top-left pad.
    - Rotate the board beforehand if it makes it easier.
5. Repeat the previous steps for all remaining hot-swap sockets.

    [![Soldered hot-swap sockets](/docs/hot-swap-sockets/step-5_thumbnail.png)](/docs/hot-swap-sockets/step-5.png)
    [![Soldered hot-swap sockets close-up](/docs/hot-swap-sockets/step-5-2_thumbnail.png)](/docs/hot-swap-sockets/step-5-2.png)
