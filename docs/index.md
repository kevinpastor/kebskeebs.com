# Getting Started

![Most of the components required](/docs/overview.png)

This guide walks through building the Challenger from scratch. Follow the pages in order.

If this is your first time soldering, read through the [Adafruit Guide To Excellent Soldering](https://learn.adafruit.com/adafruit-guide-excellent-soldering) before starting.

## Tools Required

Gather the following before you start:

- Soldering iron
- Solder, around 0.5mm diameter for SMD components
- Flux
- Tweezers, for handling small components
- Isopropyl alcohol and a brush, for cleaning flux residue
- Kapton tape or painter's tape, for holding components in place while soldering
