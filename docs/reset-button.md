# 3. Reset Button

![Reset button overview](/docs/reset-button/reset-button-overview.png)
![Reset button underside](/docs/reset-button/reset-button-underside.png)

The reset button (Panasonic EVQ-PUL02K) goes on the **top side** of the PCB.

The button has small plastic bumps (bosses) on the underside that align with holes in the PCB. If you chose a variant without bosses (EVQ-PUJ02K, EVQ-PUA02K, or EVQ-PUC02K), align the button manually so the legs sit flat in the footprint.

1. Place the reset button in its footprint. The legs only fit in one orientation; the bosses (if present) should drop into the alignment holes.
   ![Reset button positioned](/docs/reset-button/reset-button-positioned.png)
2. Solder all four legs.
   ![Reset button soldered](/docs/reset-button/reset-button-soldered.png)

> **Verify:** Press the button. It should click and spring back.
