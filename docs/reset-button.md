# 3. Reset Button

![Overview](/docs/reset-button/overview.png)

Depending on the model, the button might have small plastic bumps (bosses) on its underside to help with alignment.

![Reset button underside](/docs/reset-button/reset-button-underside.png)

1. Position the button on the top side of the PCB.
    - Ensure the "clicky side" is on the outer edge of the PCB. The button bosses, if present, should drop into the alignment holes.

    ![Reset button positioned](/docs/reset-button/step-1.png)

2. Solder all four legs.

    ![Reset button soldered](/docs/reset-button/step-2.png)

3. (Optional) Remove the tape on top of the button.
