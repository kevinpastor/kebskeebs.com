# 3. Reset Button

![Overview](/docs/reset-button/reset-button-overview.png)

The reset button goes on the **top side** of the PCB.

Depending on the model, the button might have small plastic bumps (bosses) its underside, to help with alignment.

![Reset button underside](/docs/reset-button/reset-button-underside.png)

1. Position the button. Ensure the "clicky side" is on the outer edge of the PCB. The button bosses, if present, should drop into the alignment holes.
   ![Reset button positioned](/docs/reset-button/reset-button-positioned.png)
2. Solder all four legs.
   ![Reset button soldered](/docs/reset-button/reset-button-soldered.png)
