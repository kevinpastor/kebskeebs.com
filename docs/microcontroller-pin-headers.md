# 6. Microcontroller Pin Headers

[![nice!nano overview](/docs/microcontroller-pin-headers/overview_thumbnail.png)](/docs/microcontroller-pin-headers/overview.png)

Solder the pin headers to the microcontroller so it can plug into the female headers.

1. Insert the two pin headers, short side down, into the female headers.

    [![Pin headers positioned](/docs/microcontroller-pin-headers/step-1_thumbnail.png)](/docs/microcontroller-pin-headers/step-1.png)

2. Position the microcontroller onto the pin headers.
    - It should be placed **face down** with **the top holes, labeled `B+` and `B-`, left empty**. The microcontrollller USB port should roughly align with the top edge of the PCB.

    [![Microcontroller positioned](/docs/microcontroller-pin-headers/step-2_thumbnail.png)](/docs/microcontroller-pin-headers/step-2.png)
    [![Microcontroller positioned close-up](/docs/microcontroller-pin-headers/step-2-2_thumbnail.png)](/docs/microcontroller-pin-headers/step-2-2.png)

3. Solder the edge pins of each pin header.

    [![Microcontroller soldered extremities](/docs/microcontroller-pin-headers/step-3_thumbnail.png)](/docs/microcontroller-pin-headers/step-3.png)

4. Verify the alignement of the microcontroller onto the pin headers.
5. Solder the remaining pins.

    [![Microcontroller soldered](/docs/microcontroller-pin-headers/step-5_thumbnail.png)](/docs/microcontroller-pin-headers/step-5.png)

6. Remove the microcontroller from its socket.
    - Slowly pull one side at a time to avoid bending pins.

    [![Microcontroller removal](/docs/microcontroller-pin-headers/step-6_thumbnail.png)](/docs/microcontroller-pin-headers/step-6.png)
    [![Microcontroller removed](/docs/microcontroller-pin-headers/step-6-2_thumbnail.png)](/docs/microcontroller-pin-headers/step-6-2.png)
